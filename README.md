# Job Tracker

A self-hosted job application tracker built with Next.js, Prisma, and SQLite.

## Features

- **Dashboard** — pipeline breakdown by stage, weekly application momentum, response/rejection rates, and stalled-application nudges.
- **Applications table** — add, edit, and filter applications; search by company, role, or location.
- **LinkedIn auto-fill** — paste a `linkedin.com/jobs/...` URL when adding a job and the company, role, and location fields are pulled from the posting automatically.
- **Map view** — applications plotted by location, color-coded by status, alongside a sample cost-of-living index per city.
- **Company profiles** — every company gets a page listing its applications plus freeform notes you can jot down over time.

## Getting Started

Install dependencies (this also runs `prisma generate`):

```bash
npm install
```

Set up the database — apply migrations and optionally seed sample data:

```bash
npx prisma migrate dev
npx tsx prisma/seed.ts
```

Run the dev server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the dashboard.

## Environment

Copy `.env` (or create one) with a `DATABASE_URL`. The project defaults to a local SQLite file:

```
DATABASE_URL="file:./dev.db"
```

## Tech Stack

- [Next.js](https://nextjs.org) (App Router) + React 19
- [Prisma](https://www.prisma.io) with the `better-sqlite3` driver adapter
- [Tailwind CSS](https://tailwindcss.com)
- [MapLibre GL](https://maplibre.org) for the map view

## Data Model

Applications (`Application`) track company, role, location (with lat/lng), status, and dates. `CompanyNote` stores freeform notes keyed by company name. See `prisma/schema.prisma` for details.

## Using Claude Code

This project is set up to work with [Claude Code](https://claude.com/claude-code):

- **`AGENTS.md`** (loaded automatically via `CLAUDE.md`) tells the agent that this app runs on a Next.js version with breaking changes from the training data, and to read the relevant guide under `node_modules/next/dist/docs/` before writing any Next.js code. That block is regenerated by `next dev` — if it shows up as a diff, just commit it along with your other changes.
- **Prisma skills** are installed under `.agents/skills/` (tracked in `skills-lock.json`), giving the agent up-to-date reference docs for the Prisma CLI, client API, database setup, and the v7 driver-adapter/migration APIs this project relies on (`@prisma/adapter-better-sqlite3`).
- Typical prompts that work well here: "add a new application status," "add a filter to the dashboard," "write a migration for X," or "explain how the LinkedIn auto-fill parses a posting."

No project-specific slash commands or hooks are configured — Claude Code uses its default skills and tool access.
